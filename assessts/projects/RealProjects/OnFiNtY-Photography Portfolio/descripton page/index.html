OnFiNtY Photography Portfolio

Dark-themed photography portfolio with animated particle backgrounds, gradient text effects, glassmorphism elements, and interactive portfolio galleries with modal lightbox functionality

Project Overview

Dark Theme with Gradient Accents

Sophisticated dark background (#0a0a0a) with cyan (#00f5ff) and coral (#ff6b6b) gradient accents. Animated floating particles create depth and movement across the entire viewport with CSS animations.

Interactive Portfolio Gallery

CSS Grid layout with 8 portfolio items featuring hover overlays with gradient backgrounds, modal lightbox system with keyboard navigation, and smooth scale transform hover effects.

Advanced Animation Framework

Intersection Observer scroll animations, counter animations for statistics, testimonial slider with auto-play, and staggered portfolio item reveals with transition delays.

Design Components

Fixed Navigation with Glassmorphism

Fixed top navigation with backdrop-filter blur(10px) and rgba transparency, animated underline effects on hover with gradient borders, and smooth opacity changes on scroll.

Typography with Gradient Text Effects

Playfair Display for headings and Inter for body text, gradient text using background-clip: text with -webkit-text-fill-color: transparent, plus text-shadow glow effects.

Responsive Grid Portfolio Layout

Auto-fit minmax(300px, 1fr) grid with 4:3 aspect ratios, 20px border-radius, overlay effects with linear-gradient backgrounds, and scale transform hover animations.

Testimonial Carousel System

Auto-playing testimonial slider with fade transitions, navigation arrows with opacity hover effects, circular author avatars, and 5-second interval timing.

Technical Implementation

Animated Particle Background System

JavaScript-generated floating particles with random positioning, 20-second infinite animations, and dynamic opacity transitions

Intersection Observer Animations

Scroll-triggered reveal animations with translateY transforms, threshold detection at 0.1, and staggered portfolio item delays

Modal Lightbox Gallery

Full-screen image modal with keyboard navigation (arrow keys, escape), image array cycling, and backdrop click-to-close functionality

Animated Statistics Counters

Number counting animations triggered by scroll, 40ms intervals with incremental updates, and data-count attributes for target values

Responsive Glassmorphism Design

Backdrop-filter blur effects on cards and navigation, rgba transparency with white opacity, and responsive breakpoint at 768px

Button Ripple Effects

Click-triggered ripple animations with dynamic positioning, 600ms duration, and scale transforms from center point

Design & Development Details

Color Palette: Primary dark (#0a0a0a), cyan accent (#00f5ff), coral accent (#ff6b6b), light text (#ffffff), gray text (#b3b3b3)
Typography: Playfair Display for headings with 700 font-weight, Inter for body text with 300-600 weights, responsive font sizing
Layout Architecture: CSS Grid auto-fit responsive galleries, flexbox navigation, max-width 1400px containers, 5% horizontal padding
Animation Framework: @keyframes fadeInUp with opacity/translateY, floating particle animations, pulse effects, and scroll-triggered reveals
Interactive Elements: Portfolio hover overlays, modal lightbox navigation, testimonial slider, contact form with validation
Service Categories: Wedding, Portrait, Landscape, Commercial, Event photography with emoji icons and booking CTAs
Technical Features: Intersection Observer API, keyboard event handling, smooth scrolling, form submission with FormSubmit
Development Time: 20-25 hours (advanced animations and modal system implementation)
Pricing Range: $180 - $300 (premium photography portfolio with advanced interactivity and animations)
