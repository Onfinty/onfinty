OnFiNtY Café Landing Page

Cyberpunk-themed café landing page featuring futuristic typography, animated gradient text effects, neon glow buttons, and smooth scroll animations with geometric background elements

Project Overview

Cyberpunk Dark Theme with Neon Accents

Deep dark background (#1E1E1E) with vibrant purple (#9543FF) and cyan (#00FFFF) gradient accents. Animated text with glowing effects and SVG geometric background patterns create a futuristic atmosphere.

Interactive Menu Cards with Hover Effects

CSS Grid layout with glassmorphism menu cards featuring backdrop-filter blur, scale transform hover animations, gradient circular icons, and smooth box-shadow glow effects.

Futuristic Typography & Animations

Orbitron font for headings with animated gradient text effects, Poppins for body text, scroll-triggered fade animations with Intersection Observer, and glowing button hover states.

Design Components

Full-Height Hero with Animated Gradient Text

100vh hero section with centered content, Orbitron 900 font-weight title with 45deg gradient animation cycling between purple and cyan, plus geometric SVG background overlay.

Glassmorphism Cards with Neon Borders

Menu cards with rgba(255,255,255,0.05) backgrounds, 10px backdrop-filter blur, animated purple border glow on hover, and 30px border-radius with smooth transitions.

Gradient Glow Buttons with Scale Effects

30px border-radius buttons with 45deg purple-to-cyan gradients, box-shadow glow effects, scale(1.05) hover transforms, and smooth 0.3s ease transitions.

Animated Border Contact Section

Contact section with animated gradient border using ::before pseudo-element, 200% background-size with position animation, and 30px border-radius styling.

Technical Implementation

CSS Keyframe Animations

@keyframes glowText with background-position animation, gradientBorder for contact section, and smooth 3s ease-in-out infinite cycles

Intersection Observer Scroll Animations

Scroll-triggered fade-in effects with 0.1 threshold detection, translateY(50px) to 0 transforms, and staggered menu card reveals with 100ms delays

Geometric SVG Background Pattern

Inline SVG with circles and rectangles in varying opacities, dark geometric shapes overlay, and cover background-size for full hero coverage

Advanced CSS Gradient Effects

Linear-gradient text with -webkit-background-clip, text-fill-color transparent, animated background-position, and multiple gradient overlays

Responsive Grid System

Auto-fit minmax(300px, 1fr) for menu cards, 768px breakpoint for mobile, clamp() functions for responsive typography, and grid-template-columns adjustments

Enhanced Interactive Elements

Smooth scroll behavior for anchor links, button hover scale effects, menu card transform animations, and social icon glow effects with text-shadow

Design & Development Details

Color Palette: Dark base (#1E1E1E), purple accent (#9543FF), cyan accent (#00FFFF), white text (#FFFFFF), light gray (#CCCCCC), black footer (#000000)
Typography: Orbitron for headings with 400-900 weights, Poppins for body text with 300-600 weights, clamp() responsive sizing
Layout Architecture: CSS Grid for menu cards, Flexbox for navigation and content alignment, 1200px max-width containers, 100vh hero section
Animation Framework: CSS @keyframes for gradients and borders, Intersection Observer for scroll reveals, transform scale hover effects
Interactive Elements: Glow button hover states, menu card scale transforms, social icon animations, smooth scroll navigation
Visual Effects: Backdrop-filter blur glassmorphism, box-shadow glow effects, gradient text animations, geometric background patterns
Menu Categories: Quantum Cappuccino, Cyber Iced Latte, Neon Espresso with emoji icons and email order links
Development Time: 15-20 hours (cyberpunk styling and gradient animations)
Pricing Range: $120 - $200 (modern café landing page with futuristic design elements)
