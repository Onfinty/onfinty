OnFiNtY Learning Platform

A modern educational landing page featuring advanced CSS animations, 3D effects, gradient design system, and interactive elements with navy, purple, and lime color scheme

Project Overview

Dynamic Hero Section

Full-screen hero with animated 3D graduation cap (200px circle with gradient), floating geometric shapes with 6-second animation cycles, and parallax mouse-tracking effects creating depth.

Advanced CSS Animations

Multiple animation layers: floating shapes with transform rotations, scroll-triggered fade-ins, tilt effects on feature cards using perspective transforms, and glow text animations with 3-second cycles.

Glass Morphism Design System

Cards use backdrop-filter blur effects with rgba(255,255,255,0.05) backgrounds, 1px purple borders, 20px border-radius, creating modern translucent depth effects throughout.

Design Components

3D Course Card System

Flip cards with transform-style: preserve-3d, 350px height, front/back faces using backface-visibility: hidden, hover effects with perspective(1000px) rotateY(7deg) transforms.

Animated Statistics Section

Intersection Observer API triggers counter animations with 2000ms duration, step calculations, and special formatting for percentage values with purple glow text-shadow effects.

Gradient Button System

Primary buttons use linear-gradient(135deg, #8E44FF, #6B2DC7) with 50px border-radius, box-shadow rgba(142,68,255,0.4), hover translateY(-3px) animations.

Pricing Card Layout

Three-column grid with featured card scale(1.05) transform, before pseudo-element badges, translateY(-10px) hover effects, and checkmark list styling with lime accents.

Technical Implementation

Animated Statistics Counter

Dynamic counter animations displaying 10,000+ students, 200+ courses, and 95% satisfaction rate with scroll-triggered effects

3D Card Flip Effects

Interactive course cards with front/back flip animations showing course details, instructors, and enrollment options

Floating Shape Animations

Parallax floating shapes in hero section with mouse-tracking effects and continuous rotation animations

Gradient Design System

Purple and lime gradient color scheme with navy base, creating modern educational brand aesthetics

Interactive Pricing Cards

Three-tier pricing structure with hover animations, featured plan highlighting, and ripple button effects

Student Testimonials

Testimonial section featuring student success stories with animated avatars and smooth transitions

Design & Development Details

Color Variables: --navy: #0B0F1A, --purple: #8E44FF, --lime: #A3FF12, --white: #FFFFFF, --gray: #8892B0, --dark-purple: #6B2DC7
Typography: Arial font-family, responsive font sizes (3.5rem hero h1, 2.5rem section titles), gradient text effects with -webkit-background-clip
Layout System: CSS Grid auto-fit minmax(300px, 1fr) for responsive cards, max-width containers (800px hero, 1200px sections)
Animation Framework: CSS @keyframes (float, pulse, slideInUp, glow), JavaScript Intersection Observer, mouse tracking parallax
Interactive Elements: Transform hover effects, ripple button animations, card tilt effects with mousemove calculations
Technical Features: Backdrop-filter blur, perspective transforms, counter animations, scroll-triggered effects
Mobile Responsive: @media (max-width: 768px) breakpoints, grid-template-columns: 1fr, adjusted font sizes
Development Time: 25-30 hours (advanced animations and interactive features)
Pricing: $150 - $250 (based on animation complexity and interactive feature implementation)
