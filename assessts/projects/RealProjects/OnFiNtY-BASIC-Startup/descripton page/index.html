OnFiNtY Startup Landing Page

A futuristic startup landing page featuring neon gradients, floating animations, and premium visual effects for tech innovation companies

Project Overview

Premium Startup Design

High-end futuristic design with neon blue and purple gradients, floating background shapes, and "Innovate. Scale. Succeed." messaging.

Mobile-First Approach

Responsive grid layouts that adapt seamlessly across all devices with proper breakpoints and flexible design elements.

Advanced Visual Effects

Floating animated shapes, parallax scrolling effects, and complex CSS animations with neon glow effects throughout the design.

Key Components

Hero Section with Animated Text

Orbitron font headline with animated gradient text effects, pulsing animations, and neon glow shadows for maximum visual impact.

Why us

Three value proposition cards with iconography, lift animations, and neon border glows highlighting key benefits.

Services Grid with Hover Effects

Three service cards (Technical Development, Digital Transformation, Security) with emoji icons, lift animations, and neon border glows.

Contact Section with Border Animation

Animated gradient border using CSS mask properties with hue-rotate animation creating a continuous color-shifting effect around the section.

Advanced CSS Animations

Complex keyframe animations with gradient pulses and floating effects

CSS Variables & Gradients

Custom properties for neon colors and complex gradient backgrounds

Parallax Scrolling

Background shapes move at different speeds creating depth perception

Responsive Breakpoints

Mobile-first design with proper media queries at 768px

Premium Typography

Orbitron monospace font with Poppins for futuristic aesthetic

Staggered Card Animations

Sequential reveal animations with timing delays for service cards
